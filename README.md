# SmartBin AI

SmartBin AI – Intelligent Waste Collection & Bin Overflow Monitoring System

Tech: React + Vite, Firebase Auth & Firestore, Tailwind CSS, Chart.js, Gemini API (env)

Setup
1. Copy .env.local.example to .env.local and fill values.
2. npm install
3. npm run dev

Deployment
- Configure Vercel with environment variables from .env.local
- Build command: npm run build
- Output directory: dist

Important
- Do NOT commit secrets. Use environment variables for Firebase and Gemini keys.
